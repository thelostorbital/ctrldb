# Security policy

CtrlDB operates infrastructure and may handle sensitive resource metadata.
Please do not report suspected vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting for this repository. Include a
clear reproduction, the affected version or commit, and the potential impact.
Please remove credentials, project identifiers, customer data, and other
sensitive infrastructure details from the report.

Security fixes are developed privately and disclosed after a corrected release
is available. No response-time guarantee is offered while the project remains
in early development.
